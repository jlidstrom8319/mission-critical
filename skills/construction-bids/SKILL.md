# Construction Bids

## Bid package

A bid package for a trade includes:

1. **Scope of work**: inclusions, exclusions, and clarifications written by spec section and drawing reference, plus general items (cleanup, hoisting, layout, permits, testing, temporary protection, safety, schedule participation).
2. **Documents list**: drawing sheets with revision dates, spec sections, addenda, geotech, etc.
3. **Bid form**: base bid, alternates, unit prices, allowances, schedule durations, required breakouts.
4. **Commercial terms**: subcontract form, insurance, bonding, prevailing wage/DBE/MBE requirements, retainage, payment terms.
5. **Logistics**: due date/time, pre-bid meeting, site visit, RFI cut-off, contact.

## Addenda

Track every addendum (number, date, sheets/sections affected). A bid that does not acknowledge all addenda is non-responsive or must be clarified.

## Bid leveling

Put bidders in columns, scope items in rows.

| Row | Bidder A | Bidder B | Bidder C |
|---|---|---|---|
| Base bid as submitted | | | |
| Addenda acknowledged | | | |
| Scope item 1 (incl/excl/value) | | | |
| … | | | |
| Plug for excluded scope | | | |
| Alternates | | | |
| Bond / insurance | | | |
| **Leveled total** | | | |
| Schedule / lead times | | | |
| Qualifications & exceptions | | | |

Rules:

- Add a **plug** (stated estimate, labeled as such) for each item a bidder excluded that others included, so totals compare like-for-like.
- Flag bids far below the pack (often > 10–15%) — likely a scope miss; confirm in a scope review call before relying on it.
- List every qualification/exclusion verbatim; these become subcontract negotiation items.
- Check math on bid forms; written amount vs. numeric per the bid instructions.

## Scope gap check

Cross every trade's scope against adjacent trades: who provides blocking, firestopping, sleeves, access panels, final connections, equipment setting, temporary power, testing, demolition, patching, and caulking? Every item must belong to exactly one package.

## Recommendation for award

State: recommended bidder, leveled amount, key reasons, open clarifications to resolve in the subcontract, and risks (capacity, safety record, bonding). Keep it factual; the decision belongs to the project team/owner.

## Public-bid caution

On public projects, follow the bid instructions exactly (sealed bids, opening procedures, responsiveness rules). Do not suggest post-bid negotiation where law forbids it.
